# `finch-vm-core` documentation

This directory owns implemented reference material for Finch's shared typed IR, type and signature
model, verifier, diagnostics, effects, capabilities, and serialized contract versioning.

Current concise ownership and test instructions are in [`../AGENTS.md`](../AGENTS.md), and the exact
Rust surface is generated in [`../INTERFACE.md`](../INTERFACE.md). Planned cross-frontend language
semantics remain in the shared [Finch language design](../../../docs/language/README.md) until they
are implemented and stable enough to extract into an IR/verifier reference here.
