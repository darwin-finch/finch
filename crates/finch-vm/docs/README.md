# `finch-vm` documentation

This directory owns implemented reference material for the typed interpreter, fibers, checkpoints,
host-effect suspension, and execution behavior composed by `finch-vm`.

Current concise ownership and test instructions are in [`../AGENTS.md`](../AGENTS.md), and the exact
Rust surface is generated in [`../INTERFACE.md`](../INTERFACE.md). Planned language/runtime semantics
remain in the shared [Finch language design](../../../docs/language/README.md) until implemented and
stable enough to extract into an execution reference here.
