# `finch-coforth` documentation

This directory owns implemented reference material for the Co-Forth reader, structured syntax,
type elaboration, and lowering into Finch typed stack IR.

Current concise ownership and test instructions are in [`../AGENTS.md`](../AGENTS.md), and the exact
Rust surface is generated in [`../INTERFACE.md`](../INTERFACE.md). Planned semantics shared with
CoLisp remain in the [Finch language design](../../../docs/language/README.md); they should not be
copied here. Extract a Co-Forth syntax reference here as those forms become implemented contracts.
